# Release process

* Project releases are associated with source repository tags.
  * Each release has a unique tag which represents a released version.
  * Version numbers are following the [semantic versioning](https://semver.org/).
  * Release announcements are on GitHub [releases page](https://github.com/rizsotto/Bear/releases).
* Branching model is similar to [this](https://nvie.com/posts/a-successful-git-branching-model/).
* The project currently is not containing any packaging related material.
  * Any problem to package this project can be discussed on an issue. (Will always prefer to solve the problem upstream, rather than having different patched versions.)
